# Extension Icons

Place the following icon files in this directory:

- `icon16.png` (16x16 pixels)
- `icon48.png` (48x48 pixels)
- `icon128.png` (128x128 pixels)

You can create these icons using any image editing software. The icons should represent the functionality of syncing chat contexts between different AI platforms.

Suggested design:
- Use a simple, recognizable symbol like chat bubbles or a sync icon
- Use a color scheme that's distinct but not overly bright
- Keep the design simple so it's recognizable even at the smallest size (16x16)

## Placeholder Icons

Until you create custom icons, you can use a free icon set or generate simple icons using online tools like:

1. [Icon Kitchen](https://icon.kitchen/)
2. [Favicon.io](https://favicon.io/)
3. [Canva](https://www.canva.com/)

After generating the icons, rename them to match the required filenames and place them in this directory.
